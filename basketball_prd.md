# 🏀 Basketball Player Search App – PRD

## 1. 📌 Product Overview
Ek basketball-based mobile/web app jisme user kisi bhi player ka naam search kare aur uska **complete profile + stats + history** API se fetch hokar UI me show ho.

### 🎯 Goal:
- Static data → Dynamic API-based system
- Basic list → Full player intelligence system
- Learning project → Portfolio-level project

---

## 2. 👤 Target Users
- Basketball fans
- Sports analytics learners
- Students
- Fantasy sports users

---

## 3. 🚀 Core Features

### 🔍 1. Player Search
- User input: player name
- Auto-suggestions (optional)

---

### 📊 2. Player Details Screen

#### 🧾 Basic Info
- Name
- Age
- Height / Weight
- Team
- Position
- Jersey number

#### 📈 Stats
- Points per game (PPG)
- Assists
- Rebounds
- Field goal %
- 3-point %

#### 🏆 Career Info
- Teams played
- Achievements
- Championships

#### 🖼️ Media
- Player image
- Team logo

---

### 📅 3. Recent Matches (Advanced)
- Last 5 matches stats
- Performance graph

---

### ⭐ 4. Favorites
- Save favorite players
